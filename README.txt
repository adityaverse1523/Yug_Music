YUG MUSICAL ACADEMY — Simple Website Demo

How to use:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in Chrome, Edge, or another browser.
4. Try Student Login or Admin Login. Any valid-looking email and password will open a demo dashboard.

Important:
This is a front-end demo. Real login, live classes, 500-person video capacity, payments, file uploads, notifications, attendance storage and secure student records require a backend and suitable third-party services.

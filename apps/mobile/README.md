# YUG Musical Academy — Student Mobile App (Architecture)

This folder is reserved for the cross-platform Student Mobile App (built with React Native / Expo).

### Features planned for Student App:
1. **Live Class Gateway**: Join online classes directly from the schedule.
2. **Recorded Lessons & PDFs**: View video tutorials and download sheet music / study materials.
3. **Practice Submission Studio**: Record audio/video riyaaz on the smartphone and submit directly to the professor.
4. **Teacher Feedback & Ratings**: View reviews and guidance given by the professor.
5. **Class Notifications**: Real-time notifications dispatched from the Admin Panel.
6. **Attendance & Progress**: Personal attendance history and milestone tracking.

### Shared Logic:
- Shares `@yug/shared` types with `apps/admin`.
- Connects to the same Supabase database.
